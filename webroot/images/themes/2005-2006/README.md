# 2005–2006 sky backdrop

`sky.jpg` is a dedicated, AI-generated recreation of a cloud-textured broadcast
sky, guided by the repository's existing `images/domestic.png` and the visual
character of the supplied era references. It is not an extracted original
IntelliStar background or a claim of pixel-exact reproduction.

The artwork contains no labels, logos, panels, or weather icons. These remain
separate HTML/CSS layers so live weather remains fully editable and legible.
`intellistar-32-2005-2006.css` positions the image at `100% 120%`, bottom-aligned,
to place the sun bloom just above the city strap. Semi-transparent panels let
the same cloud texture show through without repeating the image in each box.

The same image is used behind the configuration overlay. Other eras continue
using their original background. Weather icon assets remain separately managed
in `images/icons/2005-2006/`.
